# 사용자 여정 미디어의 출처와 읽는 기준

## 사용자 이해 이미지

두 페르소나와 공감지도는 서비스 이해를 위한 **설계용 가상 사례**입니다. 실제 사용자 인터뷰나 정량 조사에서 나온 결과가 아닙니다. CareerLens의 남색·인디고·흰색과 비실사 눈 심벌로 이미지 생성 도구를 사용해 제작했습니다.

- 이지원 · 취업준비자: 경험과 공고의 요구사항을 연결하고 보완할 내용을 찾는 관점
- 김도윤 · 서비스 운영·평가 담당: 처리 상태와 평가 이유를 살펴보는 관점

이해관계자 설명은 관리자 전용 전체 사용자 조회나 실제 채용사 HR 권한을 뜻하지 않습니다. 현재 대시보드는 로그인한 본인의 실행 기록을 보여줍니다.

## 실제 서비스 화면

- 출처: [팀 Render 서비스](https://agentservice-team3.onrender.com/)
- 촬영일: 2026-10-15, 한국 표준시
- 자료: 서비스에 제공된 가상 이력서 최예린 · RAG 개발자와 교육용 모의공고
- 실제 분석: 1회 실행, 종합 70점·일부 확인 필요 상태의 보고서 저장
- 이용 흐름 사진: 서비스의 내장 **가상 이벤트 시연** 상태
- 대시보드 사진: 로그인한 계정의 실행 기록. 이용 흐름에서 대시보드를 새 창으로 열었을 때 재로그인 없이 본인 기록을 확인한 화면

사진은 AI로 생성한 UI가 아니라 팀 서비스의 실제 페이지 캡처입니다. 같은 날짜에 여러 단계를 나눠 촬영했으므로 사진마다 선택 상태와 시각이 다를 수 있습니다. 실제 분석 점수는 서비스 작동 예시이며 합격 확률이나 다른 지원자와의 순위를 나타내지 않습니다.

## 두 영상의 차이

| 영상 | 실제로 담은 내용 | 편집 방식 |
| --- | --- | --- |
| `analysis-recording.mp4` | 실제 분석 1회의 로딩과 최종 보고서 | 실제 화면 40프레임을 순서대로 발췌해 약 12초로 편집. 긴 대기 구간을 생략하고 프레임 표시 시간을 재구성 |
| `flow-demo.mp4` | 이용 흐름의 내장 가상 이벤트 시연 UI | 실제 서비스에서 시연을 재생하며 얻은 35프레임을 약 13초로 편집. 이벤트·시간·진행률은 앱의 가상 값 |

두 영상은 **끊김 없는 데스크톱 녹화나 성능 측정 자료가 아닙니다.** 실제 캡처 프레임을 동영상으로 구성한 짧은 화면 기록입니다. 시연 영상은 실제 분석을 요청하거나 서버 동작 시간을 측정한 기록이 아닙니다. GIF는 MP4를 열기 전 내용을 살펴보는 미리보기입니다.

## 실시간 이용 흐름의 연결 방법과 이번 촬영 범위

1. 본 작업창 또는 대시보드에서 **이 작업창 이용 흐름 새 창 열기**를 누릅니다.
2. 열린 이용 흐름 창의 **원래 작업 창 연결됨** 상태를 확인합니다.
3. 연결된 작업창에서 행동하면 해당 작업의 흐름을 관찰합니다.

주소 `/?view=flow`를 직접 열어 연결 정보가 없는 상태와 정상 연결 상태는 다릅니다. 정상 경로로 연 창에서 실시간 모드와 원래 작업창 연결 상태를 확인했습니다.

**이번 자료에는 실제 분석이 진행되는 동안 실시간 이용 흐름까지 함께 움직이는 영상은 포함하지 못했습니다.** 실제 분석 영상과 가상 이벤트 시연 영상을 구분해 제공하며, 두 영상을 동일 실행에 연결된 실시간 기록으로 설명하지 않습니다.
