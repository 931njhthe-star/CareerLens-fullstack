## 프로젝트

### 통계 실습 자료 검색

- 기간·유형: 2026-08 ~ 2026-09 · 교육 과정 개인 프로젝트
- 목적: 통계 자료의 표와 설명을 함께 검색해 답변 근거 누락을 줄임
- 참여 인원·본인 역할: 1명, 전처리·검색·답변 API 연결·근거 검사 직접 구현
- 사용 기술: Python, LLM API, SQLite, 문서 임베딩 검색, Git, pytest
- 주요 구현: 통계 실습 자료 검색 자료를 문단별로 분리하고 문서 정보와 함께 저장. 검색된 근거를 LLM 입력에 연결하고 답변에 문서 ID 표시. 표 설명을 문단과 함께 보관
- 문제 해결: 표와 설명 문단이 분리되어 근거 누락 → 표 설명을 문단과 함께 보관
- 성과: 미등록 문서·관련 문단 없음·출처 누락 사례를 확인. 상태 그래프와 자동 업무 실행 도구는 이 프로젝트에서 사용하지 않음

### 통계 실습 자료 검색 처리 기준 정리

- 기간·유형: 2026-04 ~ 2026-05 · 교육 과제
- 본인 역할: 필수 정보와 처리 담당자, 확인 조건 정리
- 주요 수행: pandas 데이터 정제와 분류 모델 평가. 입력 누락·확인 대기 사례를 별도 항목으로 기록
- 결과: 정상 처리와 확인이 필요한 요청의 구분표 작성, 검토 의견 반영
