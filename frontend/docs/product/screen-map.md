# P1-2 화면 정보 구조와 사용자 반응 정의

이 문서는 현재 구현 화면의 텍스트 와이어프레임입니다. 모든 화면의 최종 이미지 시안과 실제 배포 검증은 별도 산출물이 필요합니다.

## 공통 구조

```text
헤더: CareerLens | 소개 | 이력서 | 채용공고 | 모의 지원 | 계정 이름 / 로그인·로그아웃
진행 단계: 이력서 → 희망 직무 → 채용 공고 → 모의지원
모의지원: 공고 목록·상세 → 모의지원 결과 확인 → 눈 모션·실제 분석 완료 → 비회원 결과 열람 인증 → 보고서
전체 알림: 성공·실패·저장되지 않은 입력 안내
푸터: 교육용 프로젝트 / 실제 기업에 지원서를 전송하지 않음
```

승인된 포슬린 테마의 흰색 작업 영역과 파란색 핵심 버튼·안내 영역을 사용합니다. 과정 화면의 점·파동·평가 요소는 회전 원으로 이어집니다. 분석 중에는 원이 가속하며 동공에 동기화되고 안쪽에서 바깥쪽으로 물결 면이 퍼진 뒤 블루 오빗 입자가 실제 보고서를 형성합니다. 희망 직무는 상단 메뉴에 포함하지 않으며 내부 과정에 맞춰 상단 메뉴를 자동 선택하지 않습니다. 진행 단계는 상단 메뉴와 분리해 작업 흐름 화면에만 표시하며 화면에 고정하지 않습니다. 희망 직무 선택은 **희망 직무** 2단계, 관련 공고 목록은 **채용 공고** 3단계, 결과는 **모의지원** 4단계입니다. 소개·인증·전체 공고 탐색 화면에는 진행 단계를 표시하지 않습니다.

| -------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 소개                 | 빛나는 점 애니메이션, 건너뛰기                                                                      | 약 2.5초 후 이력서 화면으로 이동. 건너뛰기 가능. 화면 이탈 시 타이머·이벤트 정리                                                                                                                                                                                                  |
| 비회원 이력서        | PDF/DOCX/TXT 선택, 파일명·첨부 상태, 서버 전송과 30분 보관 안내                                     | 파일 업로드·본문 추출 후 직무 선택으로 진행. 추출 본문 미리보기·직접 입력·가상 이력서 불러오기 없음                                                                                                                                                                               |
| 회원 이력서          | 가상 이력서 선택, 파일 업로드, 추출 내용 확인, 직접 입력                                            | 기존 편집·저장 기능 유지. 저장 후 희망 직무 선택                                                                                                                                                                                                                                  |
| 희망 직무            | 직무 목록, 직접 입력, 선택적 관심 분야, 관련 채용공고 보기                                          | 공개 직무 목록 조회. 선택 직무에 해당하는 DB 공고 목록으로 이동                                                                                                                                                                                                                   |
| 관련 채용공고        | 왼쪽 공고 목록·페이지 이동, 오른쪽 회사·직무·조건·기술·본문·모의지원 결과 확인 버튼                 | 선택한 공고의 상세를 오른쪽에 표시. 목록과 상세는 각각 내부 스크롤. 모바일에서는 위아래 배치. 결과 확인 클릭 즉시 눈 모션과 분석 시작                                                                                                                                             |
| 로그인/회원가입/복구 | 계정 입력, 인증 오류·진행 안내, 회원가입 이동                                                       | 로그인·회원가입·OAuth 중 비회원 자료 연결 유지. 완료 자료를 인증 후 계정의 현재 작업 공간으로 옮기고 결과 열람. 만료된 자료는 재첨부 필요                                                                                                                                         |
| 분석 오버레이        | 어두워진 공고 배경, 눈 윤곽·배경과 같은 동공, 사파이어·청록 물결 면, 분석 패널, 채용공고로 돌아가기 | 추가 질문 없이 공고 상세의 결과 확인 클릭 후 표시. 최소 4초와 실제 분석 완료를 모두 충족해야 결과로 이동. 실패 시 재시도 안내, 취소 시 공고 화면 복귀                                                                                                                             |
| 비회원 결과 확인     | 정보 없는 골격 도형의 흐림·어두운 배경, 분석 완료 모달, 로그인·회원가입·직접 파기, 만료 안내        | 보고서·점수·본문은 내려받지 않음. 모달 포커스 유지 및 배경 조작 차단. 인증과 claim 성공 후에만 보고서 표시                                                                                                                                                                        |
| 결과                 | 다른 공고로 모의지원, 목차, 내부 스크롤 보고서, 유리 3D 피라미드, 근거·보완 제안                    | 이력서 완성도·직무 적합도·지원 자격 충족도·실무 경쟁력의 랜덤 시연 점수를 표시. 꼭짓점은 평가 요소명으로 표시. 변화 시연에서는 점수 숫자 없이 내부 도형이 파랑에서 하늘색으로 변형. 이력서 보완·수정 이동 버튼 없음. 브라우저 열람만 제공하며 인쇄 버튼 없음·인쇄 CSS로 내용 숨김 |
| 전체 공고 탐색       | 검색·지역·고용·경력·기술 필터, 관심 공고, 카드·페이지 이동                                          | 기존 `#/jobs` 화면 유지. 상세·관심 저장·소유자 편집 기능 유지. 비회원도 이력서 첨부 후 공개 공고로 모의지원 가능                                                                                                                                                                  |
| 공고 직접 입력/수정  | 회사·직무·조건·기술·본문·원문 링크                                                                  | 로그인한 사용자의 입력을 DB에 저장. 필수·길이·URL 검증. 실패 시 입력 유지                                                                                                                                                                                                         |

관련 공고는 DB에 저장된 직무명과 편집 가능한 직무 별칭으로 조회합니다. 실시간 채용 API나 AI 추천 순위로 표시하지 않습니다. 가상 예시 공고는 가상 표시를 유지하며 개인 공고는 소유자에게만 보입니다. 모의지원 선택 시 서버가 DB 공고를 다시 읽으므로 브라우저가 전달한 임의 본문은 분석 기준으로 사용하지 않습니다.

## 상태·상호작용 규칙

| 입력/행동                        | 시스템 반응                                                                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 비회원의 공고 탐색               | 공개 공고만 조회. 이력서 첨부 없이도 탐색 가능                                                                                                                             |
| 비회원의 모의지원 결과 확인 클릭 | 첨부된 임시 이력서가 있으면 바로 눈 모션과 분석 시작. 없으면 이력서 첨부부터 안내                                                                                          |
| 공고 목록 클릭                   | 선택 강조와 오른쪽 상세 갱신. 빠르게 다른 공고를 고르면 이전 상세 요청 취소                                                                                                |
| 목록·상세 스크롤                 | 각 프레임 내부에서 스크롤. 모바일 상세도 제한된 높이 안에서 스크롤                                                                                                         |
| 결과 0건                         | 빈 상태와 희망 직무 수정 안내                                                                                                                                              |
| API 오류                         | 오류 문구와 재시도. 인증이 만료되면 재로그인                                                                                                                               |
| 연속 제출                        | 처리 중 버튼 비활성화. 화면·계정이 바뀐 뒤 도착한 응답으로 화면을 덮어쓰지 않음                                                                                            |
| 다른 공고로 모의지원             | 같은 이력서를 유지하고 새 공고별 기준으로 분석. 추가 답변 화면 없이 결과 확인                                                                                              |
| 이전 질문·질문 준비 링크         | 완료한 결과 또는 공고 선택 화면으로 이동. 추가 질문 화면은 표시하지 않음                                                                                                   |
| 새로고침·뒤로가기                | URL의 직무·페이지·선택 공고 복원. 첨부 완료한 비회원 상태는 세션의 임시 작업 공간에서 만료 전까지 복원하며 추출 본문·답변·보고서는 반환하지 않음                           |
| 결과 확인 모달의 키보드 조작     | Tab/Shift+Tab 포커스를 모달 안에 유지. Escape는 직접 파기 버튼으로 포커스를 옮기며 자동 삭제하지 않음. 종료 시 포커스·배경 상태 복원                                       |
| 비회원 결과에서 로그인·회원가입  | 완료 자료를 인증한 계정의 현재 작업 공간으로 교체하고 임시 DB 행 삭제. OAuth도 같은 자료 연결 유지                                                                         |
| 비회원 자료 만료·직접 파기       | 첫 유효 첨부부터 30분 후 접근 차단. 서버는 30초마다 및 시작·조회 시 만료 DB 행 정리. 서버 중지 중 만료분은 재시작 시 삭제. 직접 파기도 DB 행 삭제하며 재첨부부터 다시 시작 |
| 보고서 인쇄·PDF 인쇄             | 보고서가 인쇄 문서에 나타나지 않음. 화면 캡처·개발자 도구 복사를 완전히 막는 보안 기능은 아님                                                                              |
| 피라미드 조작                    | 마우스 이동으로 시점 변화, 휠 확대·축소. 조작 버튼 미표시, 키보드 방향키·+/- 지원                                                                                          |
| 움직임 감소·WebGL 미지원         | 연속 움직임 감소, 진행 상태 텍스트 유지. 3D 그래픽은 SVG 대체                                                                                                              |

비회원의 원본 파일은 디스크에 저장하지 않으며, 추출 이력서·답변·보고서는 별도 SQL 임시 테이블에 보관합니다. 파일 교체·분석·로그인으로 만료 시각을 늘리지 않습니다. DB 행 삭제는 저장 장치나 외부 백업의 복구 불가능한 덮어쓰기를 보증하지 않습니다. 피라미드 네 축은 실제 평가와 무관한 프론트엔드 시연 값이며 하위 항목의 실제 점수는 표시하지 않습니다. 실제 계산식과 누락 조건 처리 정책은 백엔드 담당자가 구현할 부분입니다.

P1-2의 정보 구조·스타일 일관성·핵심 사용자 동작을 구현과 문서에 반영했습니다. 모든 화면 크기·오류 종류의 완성 시안이나 실제 배포 시연을 충족했다고 주장하지 않습니다.
