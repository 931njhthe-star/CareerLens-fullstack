# 적용된 디자인 조합

현재 방향: **일반 페이지 배경 모션 제거, 분석 시에만 사파이어 동공 로딩**. 이전 고정 원·가지·방사형 섬유 정책을 대체한다.

| 항목 | 적용 |
| --- | --- |
| 전체 색감 | 포슬린 화이트·블루 |
| 보고서 배치 | 기존 스튜디오, 모바일 세로 배치 |
| 분석 로딩 | 평면 눈과 빛나는 Career Lens 로고가 교대하는 오른쪽 Y축 회전, 독립적인 동공 회전 |
| 진행률 | 동공 아래, 회전하지 않는 숫자 |
| 유리 피라미드 | 기존 클리어 사파이어 시연 |
| 결과 전환 | 상단 중앙에서 양옆으로 그려지는 은은한 테두리 빛 |

## 동공 모션

흰색 바탕에서 없는 상태로 시작하여 1.1초 동안 동공이 확대된다. 눈 위 윤곽은 왼쪽에서 오른쪽으로, 아래 윤곽은 오른쪽에서 왼쪽으로 1.6초 동안 그려진다. 윤곽 완성 후 눈 전체가 세로축(Y축)을 중심으로 오른쪽으로 돌아 40초에 한 바퀴를 완성한다. 윤곽·동공 링·광원을 하나의 평면에 두고 원근 투영해 옆면에서 층이 튀어나오지 않도록 한다. 90°에서 뒷면의 Career Lens 로고로 전환하고 180°에서 정상 방향으로 읽히며, 270°에서 눈으로 전환해 360°에서 정면으로 돌아온다. 두 면과 옆면의 가는 빛을 한 캔버스에서 그려 동시에 사라지거나 갑자기 교체되는 현상을 막는다. 로고는 Manrope 450의 윤곽을 푸른 빛점이 순차적으로 그린다. 약 3.6초 안에 글자 윤곽을 완성한 뒤 선의 밝기는 유지하고 짧은 잔광을 12초 주기로 흘린다. 빛점의 반복 이동은 그리기가 끝난 위치에서 이어지며, 채워진 글씨나 전체 로고 밝기 점멸은 사용하지 않는다. 화면 평면에서 눈 전체를 기울이는 회전은 사용하지 않는다. 동공은 이 회전과 별도로 24초에 한 바퀴 회전하며 바깥 링도 한 방향으로 돈다. 두 점선 링은 서로 다른 주기(8.2초·11.3초)로 감속해 방향을 바꾼다. 안쪽 분절 링은 매우 느리게 회전하며 순차 점등한다. 중심부는 원형 테두리 없이 은은하게 호흡하듯 빛난다. 복잡한 내부 섬유·배경, 스톡 이미지·영상과 워터마크는 사용하지 않는다.

`pupil-motion.js`는 시간 기반 기하·전환, `wordmark-motion.js`는 로고 윤곽 그리기, `wordmark-geometry.js`는 사전 계산한 글자 좌표, `live-eye-motion.js`는 캔버스 생명주기·진행률, `report-loading.js`는 실제 요청·취소·완료·결과 전환을 담당한다. 글자 원본은 [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)이며 [OFL 라이선스](../licenses/manrope-OFL.txt)를 포함한다. 실행 시 폰트 로딩이 필요하지 않다. 캔버스 해상도는 제한하고 숨김 탭에서는 프레임을 멈춘다. 모션 감소 설정에서는 정지 그림과 텍스트 진행률을 제공한다.

진행률은 평가 점수나 서버 작업 비율이 아닌 시각적 진행이다. 실제 성공 전에는 100%가 되지 않는다. 서버 완료와 최소 4초를 모두 확인한다. 실패·취소를 성공으로 꾸미지 않는다.

## 보고서 테두리

기존 `outline: 'document'` 전환을 유지한다. 입자가 실제 보고서 상단 중앙에 모이고, 빛이 양쪽 위 모서리를 돌아 양옆으로 내려가며 사라진다. 하단선·닫힌 사각형을 만들지 않는다. 긴 보고서를 작은 가짜 카드로 축소하지 않는다.

## 일반 페이지와 결과

상단 메뉴는 소개·이력서·채용공고·모의 지원, 진행표는 이력서·채용공고·모의 지원이다. 희망 직무와 공고 선택은 채용공고 내부 순서다. 배경 과정 모션과 그에 따른 반투명 표면은 제거한다.

실제 백엔드 결과와 무작위 점수 피라미드 시연의 구분을 유지한다. 보류된 실제 점수는 null로 보존한다. 보고서의 저장하기는 백엔드 별도 보관 API 준비 전까지 비활성 상태이고 PDF 내보내기는 제공하지 않는다.

`/motion-preview`와 `/design-lab`, 예전 journey 관련 모듈은 합성 비교·회귀 검증용으로 보존한다. 현재 메인 앱에서 journey 모듈이나 CSS를 불러오지 않는다.
