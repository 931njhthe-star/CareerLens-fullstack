# 구현된 사용자 흐름

현재 FastAPI 연결 기준이며, 이전 비회원 실제 평가·4단계 배경 모션 정책을 대체한다.

## 세 단계로 진행

상단 메뉴는 소개 · 이력서 · 채용공고 · 모의 지원이다. 진행표는 **이력서 → 채용공고 → 모의 지원**이다. 채용공고 내부에서 **희망 직무 선택 → 공고 선택**을 순서대로 보여 준다. 두 내부 화면 모두 상단 채용공고 메뉴와 진행표 2단계를 강조한다.

1. `#/intro`: 기존 약 2.5초 소개와 건너뛰기를 유지한다. 페이지 뒤 과정 모션은 없다.
2. `#/resume`: UTF-8 `.md` 파일만 선택한다. 업로드 전에 브라우저에서 확장자·10MiB 제한·빈 본문·잘못된 UTF-8·바이너리 파일을 검사한다. 회원의 직접 입력과 가상 이력서 예시는 유지한다. 서버와 백엔드의 검증·저장은 변경하지 않는다.
3. `#/desired-role`: 직무를 선택하거나 직접 입력한 뒤 관련 채용공고 보기로 진행한다. 저장하지 않은 직무 편집으로 단계를 건너뛰지 않는다.
4. `#/opportunities?role_id=...`: 관련 공고 목록과 상세를 함께 표시한다. 기본은 같은 원본 직무 분류이며 선택한 직무만·전체 공고로 바꿀 수 있다. 분류 정보가 없으면 전체 공고를 표시하고 사유를 안내한다. 목록은 긴 행과 화면 폭을 측정해 최소 4개가 보이는 높이를 확보하고 상세 창도 같은 높이로 맞춘다. 이전·다음 버튼은 목록만 바꾸며 열린 상세의 내용·스크롤·분석 대상은 다른 공고를 클릭할 때까지 유지한다. 현재 목록 밖의 선택도 URL과 새로고침에서 유지한다. 목록 조회 실패 시 기존 목록·상세를 유지하고 재시도를 제공한다.
5. `#/jobs`: 전체 목록에서 원본 목차의 직무 유형을 직무 분류로 제공한다. 지역·고용형태·검색 등 기존 필터와 함께 사용하며 평가에 필요한 백엔드 공고 ID를 보존한다. 공고 선택에서 들어왔을 때 **공고 선택으로 돌아가기** 버튼을 표시해 기존 직무·범위·페이지·선택 공고를 복원한다. 검색·페이지·상세·편집 이동에도 복귀 정보를 유지하며 이 정보는 백엔드 조회에 보내지 않는다. 이 필터는 추천 점수가 아니다.
6. **모의지원 결과 확인**: 실제 평가는 로그인 후 실행한다. 비회원의 파일 내용·직무·공고 준비는 탭 안에 임시 보관하며 유효 기간은 최초 첨부 후 30분이다. 로그인하면 이력서를 백엔드에 연결해 분석을 계속한다.
7. 분석: 흰색 바탕에 동공이 확대되고 눈 윤곽이 그려진다. 위 윤곽은 왼쪽→오른쪽, 아래 윤곽은 오른쪽→왼쪽으로 진행한다. 윤곽·동공은 같은 평면에서 세로축을 중심으로 오른쪽으로 천천히 회전하며, 동공 자체의 회전은 별도로 유지한다. 90° 옆면에서 은은한 푸른 빛의 Career Lens 로고로 전환해 180°에 정상 방향으로 보이고, 270°에서 눈으로 전환해 360°에 눈 정면으로 돌아온다. 중앙 광원은 테두리 없이 빛나고 진행률은 눈 아래에서 고정 표시한다. 서버 진행 단계 메시지와 시각적 백분율을 구분한다. 실제 성공 전에는 100%를 표시하지 않는다. 취소·이탈 시 백엔드 평가 취소를 요청한다.
8. `#/result`: 최소 4초 표시와 실제 완료/부분 완료 보고서를 확인한 뒤 보고서를 연다. 상단 중앙에서 좌우 테두리로 은은한 빛이 그려진다. 실제 점수·근거·부분 완료·null 점수를 그대로 유지하며 피라미드 시연은 별도 안내한다.

회원·비회원 이력서, 직무 선택, 공고 상세의 다음 버튼은 화면 오른쪽 아래에 고정한다. 모바일 안전 영역과 콘텐츠 하단 여백을 유지한다. 일반 페이지에는 배경 점·선·가지·원이 없고 입력 패널은 불투명하다.

## 결과 저장과 내보내기

완료 보고서는 현재 백엔드가 자동 기록한다. 사용자별 별도 보관 API가 없어 `저장하기`는 비활성 버튼과 준비 중 안내를 표시한다. 시연 결과는 실제 저장으로 표시하지 않는다. API가 준비되기 전에는 저장 성공을 꾸미거나 브라우저 저장으로 대체하지 않는다. [연동 대기 계약](../api/report-save-handoff.md)을 참고한다.

보고서 PDF 내보내기·인쇄 버튼을 제공하지 않는다. 기존 인쇄 방지 표시 정책을 유지한다.

## 이전 링크와 비교실

`#/job`은 희망 직무 선택으로 연결한다. `#/practice`, `#/questions`, `#/preparing`은 현재 완료 결과 또는 공고 선택 화면으로 연결하며 추가 질문 화면을 열지 않는다. `/motion-preview`, `/design-lab`은 이전 합성 모션 비교용이며 현재 운영 로딩과 다를 수 있다.

백엔드 소스·원격 DB 스키마·환경 파일은 이 UI 변경에서 수정하지 않는다. 브라우저 검증은 합성 API로 실행하며 유료 모델 평가를 실행하지 않는다.
