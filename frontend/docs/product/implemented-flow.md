# 구현된 사용자 흐름

2026-10-13 현재 프론트·FastAPI·워커 통합 기준. 이전의 비회원 준비만 제공하는 정책과 공개 운영 화면 설명을 대체한다.

## 입력부터 결과까지

1. 소개에서 약 2.5초 후 또는 건너뛰기로 이력서에 진입한다.
2. UTF-8 Markdown .md를 최대 10MB까지 첨부한다. 회원은 본문 편집·가상 이력서 선택도 가능하다. 비회원 자료는 첫 유효 첨부 시점부터 고정 30분 동안 임시 보관한다.
3. 희망 직무를 선택한다. 직접 입력 선택 시 직무명을 입력하며 별도의 관심 내용 입력란은 없다.
4. 관련 공고의 목록과 상세를 비교한다. 공고 범위·페이지를 바꿔도 열린 상세는 다른 공고를 선택할 때까지 유지한다. 전체 공고를 보고 돌아와도 선택 상태를 복원한다.
5. **모의지원 결과 확인**으로 실제 계산을 시작한다. 회원은 백엔드 API와 별도 워커를 사용한다. 비회원은 프론트 서버가 같은 평가 엔진을 불러와 계산한다. 연결 불가 시 오류를 표시하고 가짜 완료로 대체하지 않는다.
6. 눈 모션은 최소 4초 표시한다. 진행률은 실제 서버 값이다. 완료 상태와 결과 저장을 확인해야 다음 화면으로 이동한다. 취소·이탈은 해당 실행에만 취소를 요청한다.
7. 회원은 실제 보고서를 연다. 비회원은 완성된 결과를 서버에 보관하고 흐림·어둠 처리한 빈 보고서 골격 위에 로그인·가입 팝업을 표시한다. 인증 전에는 실제 점수·본문을 전달하지 않는다.
8. 비회원이 인증을 마치면 기존 결과를 계정에 연결해 조회한다. 두 번째 분석과 분석 로딩을 실행하지 않는다. 인증 후 3초 이내 열람은 목표이며 네트워크 성능 보장이 아니다. 이메일 인증이 필요하면 먼저 마쳐야 한다.

보고서의 네 축과 근거는 실제 반환값을 사용한다. 숫자 표시는 반올림하되 원본과 그래픽 좌표를 유지하며 null은 미산정이다. 무작위 점수와 가상 모션 비교는 명시적 시연에서만 제공한다. PDF·인쇄 내보내기 버튼은 제공하지 않는다.

## 저장 보고서와 운영 화면

회원 보고서는 백엔드가 저장한다. 비회원 계산 후 인증으로 연결한 결과는 프론트의 계정별 저장소에 남는다. 두 저장소는 별도이며 마이페이지와 보고서 사이드바에서 함께 조회한다. 삭제가 지원되는 결과만 선택·개별 삭제할 수 있다.

가입한 모든 회원은 마이페이지에서 대시보드와 이용 흐름을 열 수 있다. 관리자 지정은 필요하지 않다. 두 링크는 같은 탭에서 인증을 유지한다. 비회원 직접 접근과 운영 데이터 조회는 차단한다.

대시보드는 최근 서버 실행 표본을 조회한다. 이용 흐름은 공용 Redis에 도착한 브라우저·API·워커·비회원 실행 메타데이터를 수신한다. 전체 최근 기록과 선택한 대상의 41개 카드 지도를 구분한다. 다른 사용자의 원문·보고서·계정 토큰은 표시하지 않는다. 같은 브라우저 관찰과 가상 시연은 별도 모드다.

## 배포와 검증 범위

[배포 구성](../../infra/deploy/production.md)은 Caddy·프론트·API·워커·Redis와 영구 볼륨을 함께 실행한다. 프론트만 업로드하면 최신 백엔드의 회원 접근·공유 이벤트 API가 생기지 않는다. 동봉한 백엔드 반영 안내를 함께 적용해야 한다.

비회원 저장·계산은 프론트 한 인스턴스·한 프로세스 전제다. 다수 사용자 관찰을 지원해도 무제한 계산 용량이나 장애 중 이벤트 무손실을 의미하지 않는다. 실제 운영 배포·유료 모델 실행·외부 인증·부하 검증은 [검증 기록](operations-verification-2026-10-13.md)의 수행 범위를 확인한다.
