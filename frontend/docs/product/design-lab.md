# 디자인 비교실

2026-10-08 선택한 `porcelain / studio / sapphire / crystal / orbit` 조합이 실제 프로그램에 적용되었습니다. [적용 기준](selected-design.md)을 참고하세요. 비교실에서 이후 다른 옵션을 고르는 동작은 실제 프로그램의 설정을 자동으로 바꾸지 않습니다.

실제 서비스에 적용할 조합을 고르기 위한 독립 미리보기다. 프로젝트 서버를 실행한 뒤 [로컬 디자인 비교실](http://127.0.0.1:5300/design-lab)을 연다. 경로는 `/design-lab`이며 기존 소개·이력서·채용공고·보고서 화면의 디자인 설정을 바꾸지 않는다.

김하늘이라는 가상 인물과 가상 이력서·채용공고만 사용한다. 분석 API나 계정의 이력서·보고서를 읽지 않으며, 문구와 피라미드 형태는 실제 역량 평가가 아니다. 숫자 점수는 표시하지 않는다.

| 항목                 | 선택지                                                                   |

전체 색감은 흰색과 파란색을 중심으로 사이트 배경·본문·구분선의 색을 바꾼다. 전체 색감을 선택하면 어울리는 눈·피라미드·전환 팔레트도 함께 선택된다. 이후 각 항목을 따로 바꿔 조합할 수 있다. 배치 선택은 색감 선택과 독립적이다.

포커스는 요약과 피라미드를 나란히, 에디토리얼은 넓은 본문과 좁은 보조 영역에 배치한다. 컴퍼스는 피라미드 주변에 네 평가축을 놓는다. 챕터는 문서처럼 순서대로 읽으며, 브리핑은 지원자·평가축을 왼쪽 영역에 모은다. 스튜디오는 큰 피라미드와 핵심 요약을 먼저 보여 준다. 작은 화면에서는 내용이 세로로 이어지고 보고서 내부에서 스크롤한다.

## 재생과 조합 보관

- 전체 흐름을 재생하면 눈 모션을 최소 4초 보여 준 뒤, 약 2.3초 동안 입자·곡선이 보고서 윤곽으로 모인다. 보고서 내용이 드러나고 테두리 빛이 잦아든다. 전후의 짧은 대기·마무리 시간은 별도다.
- 전환만 재생하면 완료된 눈에서 보고서로 넘어가는 부분을 비교한다. 눈 색을 선택하면 눈 모션이, 전환 효과를 선택하면 해당 전환이 재생된다.
- 보고서 보기로 바로 돌아가거나 피라미드 변화 시연으로 두 예시 형태를 비교할 수 있다. 피라미드의 네 축 이름은 이력서 완성도·직무 적합도·지원 자격 충족도·실무 경쟁력이다.
- 운영체제의 모션 감소 설정을 존중한다. 다른 탭으로 이동하면 진행 중인 전체 재생을 멈추고 보고서를 보여 준다.
- 현재 조합은 주소의 `theme`, `layout`, `eye`, `pyramid`, `effect` 쿼리에 반영된다. 조합 링크 복사로 보관하거나 같은 서버에 접근할 수 있는 사람에게 전달할 수 있다. 로컬 주소 자체는 외부에 공개되지 않는다. 초기화는 기본 조합으로 돌아간다.

예: `/design-lab?theme=porcelain&layout=focus&eye=sapphire&pyramid=crystal&effect=orbit`

선택은 디자인 비교실의 URL에만 남는다. 실제 분석 서비스에 적용하려면 선택한 조합을 기준으로 별도 구현해야 한다.

선택지 이름·색상값·연동 팔레트의 기준은 `src/features/design-lab/presets.js`다. 아직 실제 서비스의 새 디자인으로 확정된 조합은 없으며, 기존 서비스의 초록색 기본 테마와 공통 디자인 기준은 유지한다. 비교실 시안을 전역 `DESIGN.md`나 디자인 토큰으로 승격하지 않는다.
