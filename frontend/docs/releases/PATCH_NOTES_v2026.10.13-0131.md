# CareerLens 프론트엔드 패치 노트

**버전: `v2026.10.13-0131` · 2026-10-13 01:31 KST**

이번 변경은 회원 운영 화면, 여러 사용자의 공용 이용 흐름 관찰, 인증·분석 경쟁 조건과 배포 구성을 보완합니다. 프론트 코드와 함께 제공하는 백엔드 패치를 적용해야 전체 기능이 연결됩니다.

## 회원 접근과 보고서

- 대시보드와 이용 흐름은 실제 로그인 회원만 조회합니다. 관리자 지정은 필요하지 않습니다. 팀원이 저장소를 받아 자신의 로컬에서 실행해도 호환되는 백엔드에 로그인하면 같은 권한으로 이용합니다.
- 마이페이지에 대시보드·이용 흐름 버튼을 제공하며 같은 탭으로 이동합니다. 토큰과 작업 상태의 `sessionStorage` 범위를 유지합니다. 직접 주소와 조회 API도 회원 여부를 확인합니다.
- 대시보드 상세는 저장된 입력·버전·해시의 의미와 출처, 노드·도구·검증·체크포인트·보고서 저장 기록을 구분합니다. 과거 미수집값이나 비용을 추정해 채우지 않습니다.
- 프론트 서버에 계정 연결된 보고서는 지원되는 삭제 API로 개별·선택 삭제합니다. 삭제 실패·미확인 응답은 성공으로 처리하지 않습니다. 기존 백엔드 보고서에는 삭제 API가 없어 같은 기능을 제공하지 않습니다.

## 공용 이용 흐름

- 기본 모드는 **실시간 · 전체 이용**입니다. API·회원 워커·프론트 비회원 엔진이 같은 Redis를 사용하면 여러 브라우저·기기의 안전한 작업 메타데이터를 약 1초 간격으로 수신합니다.
- 전체 목록은 최근 200개 이벤트, 상세 지도는 선택한 대상의 41개 카드를 표시합니다. 한 대상을 고정해도 다른 대상의 이벤트는 전체 목록에 수신합니다. 문서별 무작위 식별자와 별도 실행 기록으로 동시 작업을 구분합니다.
- 서버 보관 범위는 최대 24시간·50,000개 이벤트·5,000개 소스입니다. 전송은 최선 노력 방식이며 Redis·네트워크 장애 중 누락된 이벤트가 재접속만으로 모두 복구되는 것은 아닙니다. 공백·연결 장애·전송 대기 초과를 표시합니다.
- **이 브라우저만**은 로컬 탭 관찰, **시연 · 가상 이벤트**는 사용자가 선택하는 설명 모드입니다. 가상 시연을 실사용 기록에 섞지 않습니다. 로컬·시연 모드에서도 회원 여부를 재확인합니다.
- 계정 이름·이메일·이력서·보고서 본문·토큰·요청 원문은 공용 흐름에 포함하지 않습니다. 관찰 기록은 서버 터미널이나 무제한 감사 로그가 아닙니다.

## 경쟁 조건과 화면 반응 수정

- 자동 토큰 갱신은 같은 로그인으로 유지하고, 로그아웃·다른 계정으로 교체된 뒤 도착한 응답은 취소합니다. 늦은 세션 조회·로그인·가입·이메일 인증 응답이 새 계정을 덮어쓰지 않게 했습니다.
- 초기 `/auth/session` 404 뒤 `/me`로 전환하는 정상 호환성 탐색을 세션 실패로 표시하지 않습니다. 실제 401·서버 오류·통신 실패 기록은 유지합니다.
- 회원의 이력서 변환부터 저장까지 한 계정에 묶어, 도중 계정이 바뀌어도 다른 계정에 기존 이력서를 업로드하지 않습니다.
- 회원 분석 생성 응답을 잃어버린 경우 같은 작업 의도를 중복방지 키로 복구합니다. 진행 여부가 불명확한 요청은 유지하고, 확인된 종료 상태 이후의 새 시도는 구분합니다.
- 실패·취소된 비회원 분석의 명시적 재시도는 새 작업을 만들되 기존 입력 유효기간을 연장하지 않습니다. 취소와 계정 연결이 겹쳐도 계정에 연결된 보고서를 잘못 취소하지 않습니다.
- 실행 종료 후 내부 카드가 계속 진행 중으로 남는 문제, 사용자 PC 시계 차이로 자동 선택·정렬이 뒤틀리는 문제, 여러 페이지를 읽는 동안 대상이 빠지는 문제를 수정했습니다.
- 새 이벤트에만 유한한 빛·강조를 표시합니다. 유휴 상태, 과거 스냅샷, 숨김 복귀·재연결에서 과거 이펙트를 재생하지 않습니다. 뒤로/앞으로 가기 복원에도 인증 확인과 종료 처리를 유지합니다.

## 적용과 운영 범위

프론트·백엔드를 같은 상위 폴더의 `CareerLens-frontend`, `CareerLens-backend`로 준비하고 [백엔드 적용 안내](../api/member-shared-flow-backend.md)를 따릅니다. `member-shared-flow-backend.patch`는 기준 커밋 `3863f6eb65775a6483d35ca02b4030c876cfa16c`에 대한 21개 파일 패치입니다. 기존 팀 변경이 있으면 병합해야 하며 백엔드 저장소 업로드나 원격 DB 변경을 대신 수행하지 않습니다.

[운영 배포 구성](../../infra/deploy/production.md)은 Caddy·프론트·API·회원 워커·Redis·영구 볼륨을 포함합니다. API·워커·프론트 엔진의 Redis 주소를 같게 설정합니다. 운영에서 **새 회원 분석은 정상 워커가 없거나 Redis 상태를 확인할 수 없으면 503**으로 거절합니다. 이미 접수된 동일 요청은 기존 실행을 반환하며, 관찰 전송 실패가 진행 중 분석·완료 결과 자체를 실패로 바꾸지는 않습니다.

현재 비회원 SQLite·작업 큐는 **프론트 한 인스턴스·한 프로세스**를 전제로 합니다. 기본 동시 계산은 2건, 대기는 4건입니다. 프론트 복제·무중단 비회원 계산에는 별도 공용 작업 큐·저장소가 필요합니다. 진행 중 프론트 프로세스가 재시작되면 계산은 재시도가 필요하지만 이미 저장한 보고서는 영구 볼륨에 남습니다. 다수 사용자 관찰 지원을 무제한 분석 처리량으로 해석하지 않습니다.
