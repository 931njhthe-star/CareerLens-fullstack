## 공개 범위와 한계

GitHub에는 프론트 소스·예제 설정·설계·검증 자료를 포함한다. 실제 환경 파일·개인 DB·로그·로컬 도구 설정·실제 계정 스크린샷은 제외한다. 게시 후보의 키/JWT/개인키 패턴 검사에서 일치 항목이 없었다.

이 환경에는 Docker 실행 파일이 없어 이미지 빌드·TLS 운영 검증은 하지 못했다. 실제 유료 모델·원격 배포·이메일 회원가입·대규모 부하도 미실행이다. 목록 상세 캐시는 최대 5분이며 선택 상세는 갱신한다. 배포 시에는 원본 API·워커와 영구 볼륨을 별도로 정상 구성해야 한다.
