# 원복 후 사용자 흐름 브라우저 재검증

검증일: 2026-10-13 09:08–09:22 KST.

이 문서는 실제 Chromium 브라우저로 사용자 화면을 조작한 통합 검증이다. 실제 운영 서버 속도 측정과 구분한다. 별도 localhost:15400 프론트 서버와 15401 원본 FastAPI 라우트를 사용했고, DB는 메모리 구현, 분석 결과는 명시적인 합성 결과로 대체했다. 실제 계정·DB·유료 LLM·회원 워커에는 쓰기나 분석 요청을 보내지 않았다. 백엔드 소스는 수정하지 않았다.

## 발견 및 구분

- 실제 제품 문제: 본인 계정 API인데 대시보드가 전체 계정 집계라고 설명했다. 별도 수정 후 브라우저에서 확인했다.
- 테스트 도구 오류: 초기 합성 DB에 rubric_id 필드가 빠져 회원 분석이 503을 반환했다. QA fixture만 보정 후 원본 라우트 통과했다. 제품 수정 항목이 아니다.
- 초기 headed 검사에서 예상 밖 페이지 이동/취소가 발생했으나, 격리한 새 브라우저에서 같은 순서를 완료했고 재현되지 않았다. 이 현상을 제품 오류 해결로 주장하지 않는다.
- 시작 시 legacy /auth/session 404는 현재 API 계약 자동 감지 후 /me로 전환하는 호환 동작이며, 모든 화면에서 같은 부트스트랩이 반복될 수 있다. 사용자 화면 오류는 표시되지 않았다.

## 검증하지 않은 범위

운영 DB에 신규 회원/보고서를 생성하는 검사, 실제 유료 LLM 계산, 실제 워커 큐 처리, 운영 배포·부하 시험, 이메일 확인을 요구하는 실제 회원가입은 실행하지 않았다. 회원가입 잠금 해제·인증 실패 경계는 자동 회귀 테스트로 확인했으며 이번 브라우저 실측은 로그인 경로다. 실제 공고 100개 첫 진입·재진입·새로고침 시간은 별도의 실제 5300 서버 측정 결과를 사용해야 한다.
