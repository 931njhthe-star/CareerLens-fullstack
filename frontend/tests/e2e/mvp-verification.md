# MVP 브라우저 검증 기록

검증일: 2026-10-02 (KST). 독립 검증 서버 `127.0.0.1:5400` 및 격리된 검증 DB에서 합성 계정·합성 공고만 사용했습니다. 개인 키나 외부 AI 호출을 사용하지 않았습니다.

| 시나리오 | 관찰 결과 |
| --- | --- |
| 로그인 없이 목록 확인 | 가상 공고 30개, 12개씩 3페이지, 로그인·공고 직접 입력 동작 표시 |
| Python + 서울 검색 | 필터 URL 유지, 일치하는 6개 결과 |
| 예시 공고 상세 | 가상 예시 표시, 실제 직무 자료 참고 출처와 모집 링크 차이 표시 |
| 이력서 없이 공고 먼저 선택 → 회원가입 | 선택한 Python 공고가 대기 알림으로 보존됨 |
| 가상 이력서 선택 | 20개 목록 확인, Python 예시 500자 저장, 선택 공고 대기 보존 |
| 이력서 다음 단계 | 선택한 공고의 회사·직무·본문이 편집란에 채워짐. 저장은 별도 버튼 |
| 공고 저장 → 질문 → 분석 | 3개 질문, 준비도 69점 결과 및 자체 작성 참고 자료 3개 표시 |
| 결과 프레임 | 높이 420px, 전체 내용 3020px, overflow-y auto. 목차 클릭 후 카드 scrollTop 2011px |
| 관심 저장/해제 | 저장한 공고 1개 → 해제 → 0개와 빈 상태 표시 |
| 직접 입력 공고 | 비공개 공고 생성, 소유자 수정·삭제 표시 |
| 편집 중 상세로 나갔다 돌아오기 | 미저장 수정 값 보존, 수정 저장 후 상세 제목 갱신 |
| 다른 공고 선택 후 저장 전 기존 결과 조회 | 기존 회사·직무·결과 유지, 미저장 수정 안내 표시 |
| 검증 공고 삭제 | 삭제 확인 문구 관찰, 삭제 완료 후 목록 다시 30개 |
| 375px 화면 | 카드 한 열·필터 두 열, 가로 넘침 없음 (문서 366px ≤ 뷰포트 375px). 임시 뷰포트 설정 복원 |
| 브라우저 오류 | 검증 중 수집된 console error 0개 |

취소 분기·서로 다른 계정 간 접근 거부·SQL 저장 동시성은 이 브라우저 기록만으로 검증했다고 주장하지 않습니다. 교체 보호의 상태 함수와 소유자 UI는 JS 단위 테스트, 서버 소유권은 백엔드 테스트에서 검증합니다. 외부 OAuth, 실제 AI 제공자, 원격 배포·모든 모바일 기기는 별도 검증 대상입니다.
