# CareerLens

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

프로젝트 2는 이력서와 채용공고를 연결해 모의지원 분석과 보고서를 제공한다. 실제 기업에 지원서를 보내는 서비스가 아니다.

## Users

사용자는 이력서 준비, 희망 직무와 공고 선택, 인증, 모의지원 분석, 보고서 조회를 진행한다. 운영 대시보드는 로그인 없이 읽기 전용으로 열 수 있다. 개인 이력서·보고서와 쓰기 작업의 인증·소유권 확인은 유지한다.

## Capabilities and Constraints

프론트는 기존 Flask/Waitress 서버와 브라우저 JavaScript를 유지한다. 백엔드 소스 수정, 원격 DB 변경, 유료 분석 검증, GitHub 공개는 이번 작업 범위가 아니다. 실제 점수와 진행률은 서버 응답만 사용하며 미제공 값은 미수집으로 표시한다.

## Operating Context

2026-10-12 사용자는 로그인·이용 과정뿐 아니라 API, 로그, 그래프, 진행률로 CareerLens의 동작을 관찰하는 모션 화면을 요청했다. 첨부 레퍼런스는 어두운 노드 카드 사이로 빛이 이동하고 활성 카드가 강조되는 구성이다. 마이페이지의 대시보드에서 새 탭으로 실시간 관찰을 연다. 현재 앱 탭의 행동·API 요청과 서버가 제공하는 문서 해석·4개 영역 평가·검증·저장 이벤트를 실제 설계에 맞춰 연결한다. 다른 사용자의 접속, 서버 터미널과 제공되지 않은 내부 동작은 수집되었다고 표현하지 않는다.

## Brand Commitments

기존 서비스는 흰색·파란색 화면과 CareerLens 로고를 유지한다. 새 관찰 화면에 한해 사용자가 제공한 어두운 네트워크 모션 레퍼런스를 적용하며, 사용자의 요청에 따라 같은 흐름을 밝은 모드로도 선택해 볼 수 있다. 기존 주요 메뉴와 실제 분석 동작을 보존한다.

## Product Principles

- 실행 결과와 시연 데이터를 명확히 구분한다.
- 이용 흐름은 단계와 상태로 표현하며 개인정보나 자격증명을 복제하지 않는다.
- 관찰 화면은 서비스 사용을 방해하지 않는 별도 화면으로 연다.
- 관측되지 않은 내부 동작을 애니메이션으로 사실처럼 만들지 않는다.
