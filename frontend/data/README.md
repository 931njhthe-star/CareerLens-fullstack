# 배포용 공개 가상 채용공고

`career-postings.json`은 팀 백엔드의 `app/modules/job_postings`에 있는 숫자 이름 `.md` 공고와 `00_목록.md`의 직무 분류만 읽어 만든 공개용 스냅샷입니다. 실제 구인·구직 정보, 개인 이력서, DB 기록, 환경변수, 백엔드 실행 코드는 포함하지 않습니다.

초기 자료: 백엔드 커밋 `57bd0cf866b3c66a853f7c79d7cdace5faffefcf`, 가상 공고 100개·직무 분류 11개. 생성일 2026-10-12 KST.

프론트만 배포해 형제 백엔드 폴더가 없을 때 `/api/v1/local-data/career-markdown`이 이 파일을 제공합니다. 로컬에 원본 폴더가 있으면 기존처럼 원본을 우선하고, 명시한 `CAREERLENS_JOB_POSTINGS_DIR`가 잘못된 경우 오류를 숨기지 않습니다.

로그인한 사용자의 실제 공고·상세·평가 ID는 계속 백엔드 API가 기준입니다. 이 스냅샷을 배포한다고 백엔드 DB에 공고가 등록되거나 실제 분석이 가능해지는 것은 아닙니다.

공개 가상 공고 원본을 갱신한 뒤, 프론트 저장소 루트에서 다음 명령으로 재생성합니다. 백엔드 파일은 읽기만 합니다.

```sh
python scripts/export-job-catalog.py
```

다른 위치의 공개 원본은 `--source 경로`로 지정합니다. 생성 결과를 검토한 뒤 배포 대상에 포함합니다. Render 빌드 중 백엔드 저장소를 내려받거나 이 스크립트를 실행할 필요는 없습니다.
