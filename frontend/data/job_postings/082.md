## 082. 통신 프로토콜 지식 RAG 엔지니어

### 1. 기본 정보
- **회사명:** 모아데이타
- **공고명:** 모아데이타 통신 프로토콜 지식 RAG 엔지니어 채용
- **직무명:** 통신 프로토콜 지식 RAG 엔지니어
- **모집인원:** 1~2명
- **경력:** 관련 경력 3년 이상
- **학력:** 학사 이상

### 2. 회사 / 직무 소개
- **회사 또는 고객사 소개:** 모아데이타은 IT 시스템 이상탐지와 운영 분석, 데이터 기반 솔루션을 개발하는 기업
- **직무 소개:** 표준 문서·제품 매뉴얼·운영 절차를 버전과 장비 유형별로 검색 가능하게 구성한다. AI가 단독으로 최종 결정을 내리는 대신, 업무 도구·데이터·사람 검토를 연결하는 오케스트레이션을 담당한다.

### 3. 담당업무
- 표준 문서·제품 매뉴얼·운영 절차를 버전과 장비 유형별로 검색 가능하게 구성한다.
- AIOps·이상탐지·데이터 분석의 데이터와 기존 시스템을 연계하고, 실패·예외 상황에서 담당자가 개입할 경로를 구현한다.
- 실행 기록과 품질 지표를 수집해 RAG·데이터 흐름의 정확도·응답시간·운영 부담을 개선한다.

### 4. 자격요건
- 문서·정형 데이터 수집 및 검색 시스템을 다룬 경험
- 검색 결과와 답변의 근거·최신성을 점검하는 역량
- Python과 SQL을 사용한 데이터 처리 경험
