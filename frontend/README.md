# CareerLens Frontend

**최신 버전: `v2026.10.13-0925` · 2026-10-13 09:25 KST**

대시보드와 이용 흐름은 로그인한 모든 회원이 관리자 지정 없이 이용합니다. 대시보드는 **내 계정의 평가 기록**을 표시합니다. 이용 흐름은 **작업 창 A와 관찰 창 A, B와 B, C와 C를 고정 연결**하며 다른 창의 활동으로 자동 전환하지 않습니다. Redis와 전체 사용자 중앙 수집은 사용하지 않습니다.

공고 목록은 프론트 서버에서 기존 API의 상세 조회를 병렬 처리하고 계정별로 최대 5분 캐시합니다. 매 요청의 인증·최신 목록 확인과 선택 공고의 새 상세 조회는 유지합니다. 분석 단계 전달, 일시적 연결 실패 복구, 백그라운드 관찰 창 재연결과 계정 범위 표시를 함께 수정했습니다.

## 실행과 백엔드 기준

백엔드는 `3863f6eb65775a6483d35ca02b4030c876cfa16c` 기준본을 사용합니다. 이전 `v2026.10.13-0131`의 공용 흐름용 백엔드 패치와 Redis 구성은 이번 버전에 적용하지 않습니다. 기존 백엔드 API를 호출하는 프론트 수정만 적용합니다. 원격 DB 마이그레이션을 자동 실행하지 않습니다.

프론트와 백엔드를 같은 상위 폴더에 `CareerLens-frontend`, `CareerLens-backend`로 둡니다. Python 3.12+ 환경에서 다음을 실행합니다.

```powershell
python -m venv .venv
./.venv/Scripts/python -m pip install -r requirements.txt -r ../CareerLens-backend/requirements.lock.txt
Copy-Item .env.example .env
./.venv/Scripts/python server.py
```

프론트 설정은 `BACKEND_URL=http://127.0.0.1:5301`, `FRONTEND_PORT=5300`입니다. `BACKEND_URL`에는 `/api`를 붙이지 않습니다. 백엔드 API와 회원 평가 워커는 별도로 실행해야 합니다. 프로젝트 상위 폴더의 실행 도구가 제공되면 해당 안내를 따릅니다. PC를 끄면 로컬 서버와 워커도 종료됩니다.

Supabase·모델 키·DB 접속 정보는 무시되는 서버 환경 파일에만 둡니다. 브라우저 JavaScript, 공개 파일, Git에 키·이력서·보고서·개인 DB를 넣지 않습니다. 원격 백엔드는 접근 가능한 HTTPS 주소를 사용합니다. `127.0.0.1`은 실행 중인 PC 자신입니다.

## 회원 화면과 창별 연결

마이페이지에서 대시보드와 이용 흐름을 엽니다. 인증은 브라우저 `sessionStorage` 범위를 따릅니다. 다른 작업 창의 로그인 상태를 임의로 공유하지 않습니다. 비회원 직접 접근은 인증 안내로 전환합니다.

이용 흐름은 연결한 작업 창의 행동·API 응답·기존 진행 조회만 표시합니다. 서로 다른 작업 창과 관찰 창을 각각 연결하면 이벤트가 섞이지 않습니다. 자동 대상 추적, 전체 사용자 목록, Redis 수집, 다른 PC의 요청 관찰은 제공하지 않습니다. 고정 연결이 끊겨도 다른 창으로 자동 이동하지 않습니다.

41개 카드와 기존 모션을 유지합니다. 새 이벤트에만 짧은 빛·강조를 표시하고 요청이 없을 때는 중립 상태로 돌아갑니다. 새로고침·재연결로 복원한 과거 상태에 효과를 재생하지 않습니다. 명시적인 가상 시연은 실제 요청과 구분합니다.

대시보드는 기존 `/evaluations`와 본인 결과 응답을 사용합니다. 기존 백엔드 관리 API의 권한을 우회하거나 전체 계정 데이터를 조회하지 않습니다. 서버가 제공하지 않는 상세 버전·해시·토큰·검증·노드·체크포인트는 미수집으로 표시하며, 현재 설정이나 추정값으로 채우지 않습니다. 조회 실패와 정상적인 0건을 구분합니다.

## 분석과 보고서

회원 분석은 기존 FastAPI와 워커를 사용합니다. 비회원은 프론트 Python 서버가 기존 엔진으로 실제 분석하고 비공개 임시 저장소에 결과를 보관합니다. 로그인·가입 후 이미 계산한 결과를 계정에 연결하며 두 번째 분석을 시작하지 않습니다. 이메일 확인이 필요한 가입은 인증 완료가 먼저 필요합니다. 인증 후 3초 이내 표시는 목표이며 네트워크 시간을 포함해 보장하지 않습니다.

입력은 UTF-8 Markdown, 최대 10MiB입니다. 비회원 임시 보관은 최초 유효 첨부부터 최대 30분이며 파일 교체로 늘리지 않습니다. 인증 전 결과 본문·점수는 브라우저에 전달하지 않습니다. 연결한 비회원 결과는 프론트 서버의 개인 저장소에 남으며 기존 백엔드 DB로 자동 이관하지 않습니다. 지원되는 프론트 저장 보고서만 실제 API로 삭제하고 실패한 삭제는 목록에 남깁니다.

최종 재검증은 JavaScript 866개, 프론트 Python 113개와 하위 검사 171개, 원본 백엔드 27개를 통과했습니다. [최종 검증 기록](docs/verification/release-20261013-0925.md)에 실제 브라우저 결과와 미검증 범위를 구분했습니다. 0719 창별 연결 검증표는 해당 시점의 기록으로 보존합니다.

```powershell
node --test tests/unit/*.test.mjs
python -m pytest -q
node scripts/sync-api-contract.mjs --check
```

운영에는 프론트 서버·기존 백엔드 API·회원 워커·Supabase·프론트 보고서 영구 저장소가 필요합니다. Redis는 필요하지 않습니다. 비회원 큐와 SQLite 저장소는 현재 프론트 한 인스턴스·한 프로세스를 전제로 하며 기본 동시 계산은 2건, 대기는 4건입니다. 프론트만 정적으로 배포하면 비회원 실제 분석이 동작하지 않습니다.

실제 운영 Docker/TLS·이메일 인증·유료 모델·실제 DB·부하 시험은 별도입니다. [이전 24장 설계서](docs/design/CareerLens_프로젝트2_화면설계서_v2_20261013.pptx)는 보존하며 최신 정책은 v3를 따릅니다.
