## 프로젝트

### 장애 알림 요약

- 기간·유형: 2026-02 ~ 2026-05 · 업무 팀 프로젝트
- 목적: 장애 ID로 알림을 묶고 재시도 상한을 적용
- 참여 인원·본인 역할: 4명, 본인은 API·상태·오류 처리 담당. 화면과 입력 자료 구성은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest, PostgreSQL, Docker
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 장애 ID 기준 묶음 처리와 재시도 상한 적용; 조회 실패 재시도는 최대 2회로 제한. 요청 ID별 실행 상태·오류 로그 저장, 컨테이너 기반 내부 실행 환경 관리
- 문제 해결: 다수 알림이 같은 장애에 중복 연결됨 → 장애 ID 기준 묶음 처리와 재시도 상한 적용
- 성과: 동일한 합성 사례 65건에서 기대 분기와 일치한 사례가 56건에서 63건으로 증가. 불일치 2건을 후속 검토 목록으로 관리
