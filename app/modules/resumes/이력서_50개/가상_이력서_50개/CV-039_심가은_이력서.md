## 프로젝트

### 교육 상담 흐름

- 기간·유형: 2026-08 ~ 2026-09 · 팀 학습 프로젝트
- 목적: 질문 ID를 유지해 조회 결과가 다른 상담 요청에 연결되지 않도록 처리
- 참여 인원·본인 역할: 2명, 본인은 상태·분기·도구 연결 담당. 화면은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 질문 ID를 상태에 보관해 결과 연결; 조회 실패 재시도는 최대 2회로 제한
- 문제 해결: 조회 결과와 사용자 질문이 다른 요청에 연결됨 → 질문 ID를 상태에 보관해 결과 연결
- 성과: 동일한 합성 사례 59건에서 기대 분기와 일치한 사례가 50건에서 55건으로 증가. 불일치 4건을 후속 검토 목록으로 관리
