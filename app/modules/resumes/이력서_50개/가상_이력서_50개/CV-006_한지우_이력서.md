- 기간·유형: 2026-08 ~ 2026-09 · 팀 학습 프로젝트
- 목적: 연속 질문의 응답을 올바른 메시지에 연결하고 진행 상태를 화면에 표시

- 주요 구현: AI 채팅 요청 관리에 질문 입력, 응답 대기, 도구 실행 상태와 오류 표시 구현. 요청 ID 기준으로 메시지를 갱신
