## 프로젝트

### 복지 신청 안내

- 기간·유형: 2026-08 ~ 2026-09 · 직무 전환 개인 프로젝트
- 목적: 복지 신청 조건의 근거를 제시하고 미확인 정보를 질문으로 반환
- 참여 인원·본인 역할: 1명, 전처리·검색·답변 API 연결·근거 검사 직접 구현
- 사용 기술: Python, LLM API, SQLite, 문서 임베딩 검색, Git, pytest
- 주요 구현: 복지 신청 안내 자료를 문단별로 분리하고 문서 정보와 함께 저장. 검색된 근거를 LLM 입력에 연결하고 답변에 문서 ID 표시. 조건 문단을 제시하고 미확인 정보를 질문으로 반환
- 문제 해결: 개인 상황에 따라 달라지는 조건을 단정 → 조건 문단을 제시하고 미확인 정보를 질문으로 반환
- 성과: 미등록 문서·관련 문단 없음·출처 누락 사례를 확인. 상태 그래프와 자동 업무 실행 도구는 이 프로젝트에서 사용하지 않음
