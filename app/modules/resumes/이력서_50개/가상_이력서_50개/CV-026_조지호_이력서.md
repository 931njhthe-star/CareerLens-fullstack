## 프로젝트

### 지표 조회 에이전트

- 기간·유형: 2026-08 ~ 2026-09 · 팀 학습 프로젝트
- 목적: 조회 기간을 확인한 뒤 SQL 지표 조회 도구를 실행
- 참여 인원·본인 역할: 2명, 본인은 상태·분기·도구 연결 담당. 화면은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 기간 누락 시 재질문 후 조회하도록 분기; 조회 실패 재시도는 최대 2회로 제한
- 문제 해결: 질문에 기준 기간이 없는데 도구 실행 → 기간 누락 시 재질문 후 조회하도록 분기
- 성과: 동일한 합성 사례 46건에서 기대 분기와 일치한 사례가 37건에서 43건으로 증가. 불일치 3건을 후속 검토 목록으로 관리
