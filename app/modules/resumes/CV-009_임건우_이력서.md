## 프로젝트

### 문서 요약 검증 흐름

- 기간·유형: 2026-08 ~ 2026-09 · 팀 학습 프로젝트
- 목적: 요약 답변에 표시된 문서 ID가 허용된 출처인지 확인
- 참여 인원·본인 역할: 2명, 본인은 상태·분기·도구 연결 담당. 화면은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 출처 허용 목록 검사 노드 추가; 조회 실패 재시도는 최대 2회로 제한
- 문제 해결: 존재하지 않는 문서 ID가 출처로 표시됨 → 출처 허용 목록 검사 노드 추가
- 성과: 동일한 합성 사례 29건에서 기대 분기와 일치한 사례가 20건에서 27건으로 증가. 불일치 2건을 후속 검토 목록으로 관리
