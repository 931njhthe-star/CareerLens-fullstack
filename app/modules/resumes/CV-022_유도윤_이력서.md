## 프로젝트

### 고객 문의 배정

- 기간·유형: 2026-08 ~ 2026-09 · 직무 전환 팀 프로젝트
- 목적: 문의 분류가 불확실할 때 재질문한 뒤 담당 부서를 배정
- 참여 인원·본인 역할: 2명, 본인은 상태·분기·도구 연결 담당. 화면은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 분류 불확실 시 재질문 상태 추가; 조회 실패 재시도는 최대 2회로 제한
- 문제 해결: 분류가 모호해도 부서 배정이 진행됨 → 분류 불확실 시 재질문 상태 추가
- 성과: 동일한 합성 사례 42건에서 기대 분기와 일치한 사례가 33건에서 39건으로 증가. 불일치 3건을 후속 검토 목록으로 관리
