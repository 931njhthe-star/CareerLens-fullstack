## 프로젝트

### 장치 점검 흐름

- 기간·유형: 2026-08 ~ 2026-09 · 팀 학습 프로젝트
- 목적: 필수 장치 상태를 확인한 뒤 점검 작업을 요청
- 참여 인원·본인 역할: 2명, 본인은 상태·분기·도구 연결 담당. 화면은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 상태 확인과 실행 전 확인 노드 분리; 조회 실패 재시도는 최대 2회로 제한
- 문제 해결: 필수 장치 상태 없이 후속 작업 요청 → 상태 확인과 실행 전 확인 노드 분리
- 성과: 동일한 합성 사례 54건에서 기대 분기와 일치한 사례가 45건에서 51건으로 증가. 불일치 3건을 후속 검토 목록으로 관리
