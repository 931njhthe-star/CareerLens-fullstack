## 프로젝트

### 문서 접근 확인

- 기간·유형: 2026-08 ~ 2026-09 · 팀 학습 프로젝트
- 목적: 사용자 권한을 확인한 뒤 접근 가능한 문서만 답변 근거로 사용
- 참여 인원·본인 역할: 2명, 본인은 상태·분기·도구 연결 담당. 화면은 팀원 담당
- 사용 기술: Python, FastAPI, Pydantic, LangGraph, LLM API, Git, pytest
- 주요 구현: 입력 검증 → 조건 분기 → 도구 조회·업무 실행 → 결과 확인 → LLM 응답 → 출력 검사 구성. 도구 실행 전에 사용자 권한 검사; 조회 실패 재시도는 최대 2회로 제한
- 문제 해결: 권한 없는 문서가 답변 근거에 포함됨 → 도구 실행 전에 사용자 권한 검사
- 성과: 동일한 합성 사례 64건에서 기대 분기와 일치한 사례가 55건에서 63건으로 증가. 불일치 1건을 후속 검토 목록으로 관리
